# 一个需求引出反射
1. **传统方式的问题**：传统方式 (`new Cat().hi()`) 是硬编码。如果需要更换调用的类（例如改为 `Dog`）或方法（例如改为 `cry`），必须修改 Java 源码并重新编译、部署。
2. **解决方法**：使用配置文件+反射
+ reflection.properties

```java
classfulpath = 
method = hi
```

3. **存在的问题**
+ 从 properties 配置文件读取出来的`classfulpath`和`method`是字符串，所以不能通过`new classfulpth`创建对象，这就需要通过反射来解决
4. **示例**

package com.aurora.ReflectionDemo.Introduction;

import java.io.FileWriter;

# 反射机制
## Java Reflection
1. <font style="color:rgb(31, 35, 40);">反射机制允许程序在执行期借助于 </font>`<font style="color:rgb(31, 35, 40);background-color:rgba(129, 139, 152, 0.12);">Reflection API</font>`<font style="color:rgb(31, 35, 40);"> 取得任何类的内部信息(比如成员变量，构造器，成员方法等等)，并能操作对象的属性及方法。反射在设计模式和框架底层都会用到。</font>
2. <font style="color:rgb(31, 35, 40);">加载完类之后，在堆中就产生了一个Class类型的对象( 一个类只有一个Class对象)，这个对象包含了类的完整结构信息。通过这个对象得到类的结构。这个Class对象就像一面镜子,透过这个镜子看到类的结构,所以,形象的称之为：反射。</font>

<font style="color:rgb(31, 35, 40);">类比：</font>

<font style="color:rgb(31, 35, 40);">p对象 ---> 类型Person类</font>

<font style="color:rgb(31, 35, 40);">Class对象cls ---> 类型Class类</font>

## <font style="color:rgb(31, 35, 40);">Java 反射机制原理示意图</font>

1. **编译阶段**
+ **图示内容**：`Cat.java` -> (javac 编译) -> `Cat.class`
+ **发生了什么**：
    - 写好了源码 `Cat.java`。
    - 通过 `javac` 编译器，源码被编译成了字节码文件 `Cat.class`。
+ **关键点**：此时，代码还只是硬盘上的一个文件，还没有进入内存。
2. **加载阶段**
+ **图示内容**：`ClassLoader`（类加载器）将字节码加载到内存中，并在 **堆 (Heap)** 中生成了一个 **Class 类对象**。
+ **发生了什么**：
    - 这是反射的核心入口。
    - 这个 `Class` 对象（图中写着 `Class类对象 Cat`）就像一面镜子，它包含了 `Cat` 类的所有完整结构信息（成员变量、构造器、方法等）。
+ 对应第一节例子中的代码：

```java
// 这行代码触发了类加载
Class cls = Class.forName("com.aurora.ReflectionDemo.Introduction.Cat");
```

+ `cls` 变量引用的就是堆里的这个 `Class` 对象。  
3. **运行阶段**
+ **图示内容**：
    - **堆 (Heap)**：存放 `new` 出来的具体实例（比如 `Cat` 对象）。
    - **方法区 (Method Area)**：存放类的二进制代码（方法的实际逻辑）。
+ **发生了什么**：
    - 当你创建对象时，对象知道自己属于哪个 `Class`。
    - **反射让你能通过 **`**Class**`** 对象反向操控具体的实例。**
+ **对应第一节例子中的代码**

```java
// 使用 Class 对象创建一个具体的 Cat 实例
Object o = cls.newInstance(); 

// 通过 Class 对象获取方法对象 (指向方法区中的具体逻辑)
Method method1 = cls.getMethod("hi"); 

// 调用方法
method1.invoke(o);
```

## Java 反射机制可以完成的操作
1. <font style="color:rgb(31, 35, 40);">在运行时判断任意一个对象所属的类</font>
2. <font style="color:rgb(31, 35, 40);">在运行时构造任意一个类的对象</font>
3. <font style="color:rgb(31, 35, 40);">在运行时得到任意一个类所具有的成员变量和方法</font>
4. <font style="color:rgb(31, 35, 40);">在运行时调用任意一个对象的成员变量和方法</font>
5. <font style="color:rgb(31, 35, 40);">生成动态代理</font>

## 反射相关的主要类
1. `<font style="color:rgb(31, 35, 40);">java.lang.Class</font>`<font style="color:rgb(31, 35, 40);">:代表一个类，Class对象表示某个类加载后在堆中的对象</font>
2. `<font style="color:rgb(31, 35, 40);">java.lang.reflect.Method</font>`<font style="color:rgb(31, 35, 40);">:代表类的方法, Method对象表示某个类的方法</font>
3. `<font style="color:rgb(31, 35, 40);">java.lang.reflect.Field</font>`<font style="color:rgb(31, 35, 40);">:代表类的成员变量,Field对象表示某个类的成员变量</font>
4. `<font style="color:rgb(31, 35, 40);">java.lang.reflect.Constructor</font>`<font style="color:rgb(31, 35, 40);">:代表类的构造方法,Constructor对象表示构造器</font>

这些类都在`java.lang.reflect`

5. 示例

```java
package com.aurora.ReflectionDemo.ReflectionMachanism;

import com.aurora.ReflectionDemo.Introduction.Cat;

import java.io.FileInputStream;
import java.io.IOException;
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.Properties;

public class ReflectionClassDemo01 {
    public static void main(String[] args) throws IOException, ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException, NoSuchFieldException {
        //1. 使用Properties 类, 可以读写配置文件
        Properties prop = new Properties();
        prop.load(new FileInputStream("module3/src/com/aurora/ReflectionDemo/Introduction/file_test/reflection.properties"));

        String classfullpath = prop.getProperty("classfullpath").toString();
        String methodName = prop.getProperty("method").toString();

        //2. 使用反射机制解决
        //(1) 加载类, 返回Class类型的对象cls
        Class cls = Class.forName(classfullpath);

        //(2) 通过 cls 得到你加载的类 com.aurora.ReflectionDemo.Introduction.Cat 的对象实例
        Object o = cls.newInstance();
        Cat cat = (Cat) o;
        cat.setName("tom");
        cat.setAge(10);

        //(3) 通过 cls 得到你加载的类 com.hspedu.Cat 的 methodName"hi"  的方法对象
        //    即：在反射中，可以把方法视为对象（万物皆对象）
        Method method = cls.getMethod(methodName);

        //(4) 通过method1 调用方法: 即通过方法对象来实现调用方法
        method.invoke(o);   //传统方法 对象.方法() , 反射机制 方法.invoke(对象)

        //(5) java.lang.reflect.Field: 代表类的成员变量, Field对象表示某个类的成员变量
        // getField只能得到public修饰的属性
        Field nameField = cls.getField("name");
        System.out.println("name:" + nameField.get(o));
        Field ageField = cls.getField("age");
        System.out.println("age:" + ageField.get(o));

        //java.lang.reflect.Constructor: 代表类的构造方法, Constructor对象表示构造器
        //()中可以指定构造器参数类型, 返回无参构造器
        Constructor constructor = cls.getConstructor();
        System.out.println("constructor:" + constructor);   //constructor:public com.aurora.ReflectionDemo.Introduction.Cat()

        Constructor constructor2 = cls.getConstructor(String.class, int.class); //constructor2:public com.aurora.ReflectionDemo.Introduction.Cat(java.lang.String,int)
        System.out.println("constructor2:" + constructor2);
    }
}
```

6. 注意事项
+ `getField()`只能得到`public`修饰的属性
+ `getConstructor()`不传入参数时得到的是无参构造器，如果想得到有参构造器，传入的参数必须与要获取的那个有参构造器的参数类型的 Class 对象完全一致，且顺序必须相同
    - 例如：有参构造器为` public Cat(String name, int age)`
    - 那么获取它的方式必须是` getConstructor(String.class, int.class);`

## 反射的优缺点
1. **<font style="color:rgb(31, 35, 40);">优点</font>**
+ **动态性**：可以在运行期间动态地创建对象和调用方法，不需要在编译期就确定下来。
+ **灵活性**：是各种主流框架（Spring, MyBatis, Hibernate）的底层核心。没有反射，这些框架无法实现解耦和动态配置。
2. **<font style="color:rgb(31, 35, 40);">缺点</font>**
+ **性能损耗**：反射基本是**解释执行**，需要进行一系列的类型检查、安全检查等，执行速度远慢于直接的代码调用。

## 反射调用的优化 _ 关闭访问检查
1. `**setAccessible(boolean flag)**`方法
+ **作用**：启动或禁用访问安全检查的开关
+ `Method`、`Field`、`Constructor`对象都有`setAccessible`方法
+ **参数说明**
+ `**true**`：取消访问检查。
    - **效果**：提高反射的效率。
    - **原理**：告诉 JVM 在执行反射调用时，不要去检查该成员是否为 `private`/`protected`，也不要检查调用者是否有权限，直接执行。
+ `**false**`：执行访问检查 (默认值)。
2. 示例

```java
package com.aurora.ReflectionDemo.ReflectionMachanism;

import com.aurora.ReflectionDemo.Introduction.Cat;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;

public class ReflectionOptimize {
    public static void main(String[] args) throws ClassNotFoundException, InvocationTargetException, InstantiationException, IllegalAccessException, NoSuchMethodException {

        //m1();
        //m2();
        m3();
    }

    public static int times = 1000000;
    //传统方式调用Cat的hi方法
    public static void m1(){
        Cat cat = new Cat();
        long start = System.currentTimeMillis();
        for (int i = 0; i < times; i++) {
            cat.hi();
        }
        long end = System.currentTimeMillis();
        System.out.println("传统方式调用Cat的hi方法" + times + "次耗时：" + (end - start));
    }

    //反射方式调用Cat的hi方法
    public static void m2() throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException {
        Class cls = Class.forName("com.aurora.ReflectionDemo.Introduction.Cat");
        Object o = cls.newInstance();
        Method hi = cls.getMethod("hi");
        long start = System.currentTimeMillis();
        for (int i = 0; i < times; i++) {
            hi.invoke(o);
        }
        long end = System.currentTimeMillis();
        System.out.println("反射方式调用Cat的hi方法" + times + "次耗时：" + (end - start));
    }

    //优化后的反射方式调用Cat的hi方法
    public static void m3() throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException {
        Class cls = Class.forName("com.aurora.ReflectionDemo.Introduction.Cat");
        Object o = cls.newInstance();
        Method hi = cls.getMethod("hi");
        hi.setAccessible(true);
        long start = System.currentTimeMillis();
        for (int i = 0; i < times; i++) {
            hi.invoke(o);
        }
        long end = System.currentTimeMillis();
        System.out.println("优化后的反射方式调用Cat的hi方法" + times + "次耗时：" + (end - start));
    }
}
```

# Class类
## 基本介绍
1. Class也是类，它也继承自 `Object` 类；它用于描述“类”本身的结构（类名、属性、方法、构造器等）。
2. `Class` 类对象不是由用户通过 `new Class()` 创建的，而是由 **系统（JVM）** 创建的。
+ **原理**：通过 `ClassLoader` 类加载器中的 `loadClass()` 方法完成加载。

```java
/* ClassLoader 源码片段 */
public Class<?> loadClass(String name) throws ClassNotFoundException {
    return loadClass(name, false);
}
```

3. **内存中的单例性**：
+ 对于某个类的 `Class` 类对象，**在内存中只有一份**。
+ 类只会被加载一次。无论是通过 `new` 还是 `Class.forName`，获取到的都是同一个 `Class` 对象。

```java
package com.aurora.ReflectionDemo.ClassDemo;

public class ClassIntroduction {
    public static void main(String[] args) throws ClassNotFoundException {
        //Class类的单例性
        Class cls1 = Class.forName("com.aurora.ReflectionDemo.Introduction.Cat");
        Class cls2 = Class.forName("com.aurora.ReflectionDemo.Introduction.Cat");
        System.out.println(cls1.hashCode() == cls2.hashCode());	//true
    }
}
```

## Class 类的常用方法
1. `static Class forName(String name)`：根据类的全限定名（包名+类名）加载类，并返回该类的 `Class` 对象。
2. `Object newInstance()`：用类的**无参构造器**创建对象实例。
3. `getName()`：获取类的完整名称（包含包路径）
4. `Field getField() / Field[] getFields()`：获取 单个/所有 `public`修饰的属性
5. `Class[] getInterfaces()`：获取当前 Class 对象的接口
6. `ClassLoader getClassLoader()`：返回该类的类加载器
7. `Class getSuperClass()`：返回表示此 Class 所表示的实体的超类的 Class
8. `Constructor[] getConstructors()`：返回一个包含某些 Constructor 对象的数组
9. `Field getDeclaredField() / Field[] getDeclaredFields()`：获取**所有修饰符**的属性，但**只包含本类**的。
10. `Method getMethod(String name, Class<?>... parameterTypes)`：返回一个 Method 对象，此对象的形参类型为 paramType

```java
package com.aurora.ReflectionDemo.ClassDemo;

import java.lang.reflect.Field;

public class ClassMethodsDemo {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchFieldException {
        String ClassPath = "com.aurora.ReflectionDemo.ClassDemo.Car";
        //1. 获取Car对应的Class对象
        Class<?> cls = Class.forName(ClassPath);

        //2.输出cls
        System.out.println(cls);    //显示cls对象, 是哪个类的Class对象 com.hspedu.Car
        System.out.println(cls.getClass()); //输出cls运行类型 java.lang.Class

        //3.得到包名
        System.out.println(cls.getPackage().getName());

        //4. 得到全类名
        System.out.println(cls.getName());

        //5. 通过cls创建实例
        Car car = (Car) cls.newInstance();
        System.out.println(car);    //Car{brand='null', price=null},返回的是car.toString

        //6. 通过反射属性获取brand
        Field brand = cls.getField("brand");
        System.out.println(brand.get(car));     //null

        //7. 通过反射给属性赋值
        brand.set(car, "benz");
        System.out.println(brand.get(car)); //benz

        //8. 得到所有的属性
        Field[] fields = cls.getFields();
        for (Field field : fields) {
            System.out.println(field.getName());
        }
    }
}
```

## 获取 Class 类对象
1. 方式一：`Class.forName()`
+ **前提**：已知一个类的全类名（String），且该类在类路径下。
+ **代码**：`Class cls = Class.forName("java.lang.Cat");`
+ **特点**：可能抛出 `ClassNotFoundException`。
+ **应用场景**：多用于**配置文件读取**，动态加载类。这是框架（如 Spring）底层最常用的方式。
2. 方式二：`类名.class`
+ **前提**：编译时已知具体的类。
+ **代码**：`Class cls = Car.class;`
+ **特点**：最为安全可靠，程序性能最高（不需要调用方法）。
+ **应用场景**：多用于**参数传递**，例如反射获取构造器时指定参数类型 `getMethod("name", String.class)`。
3. 方式三：`对象.getClass()`
+ **前提**：已经持有某个类的**实例对象**。
+ **代码**：`Class cls = 对象.getClass();`
+ **特点**：获取的是对象的**运行类型**（Runtime Type）。
+ **应用场景**：已有对象实例，想了解该对象内部结构时使用。
4. 方式四：类加载器
+ **前提**：已知全类名，且有类加载器实例。
+ **代码：**

```java
ClassLoader cl = 对象.getClass().getClassLoader();
Class cls = cl.loadClass("类的全类名");
```

+ **应用场景**：通常在复杂的类加载环境下使用，或者需要自定义类加载行为时。

5. 方式五：`基本数据类型.class`
+ **前提**：针对基本数据类型 (`int`, `char`, `boolean`, `float`, `double`, `byte`, `long`, `short`)。
+ **代码**：`Class cls = int.class;`
+ **注意**：基本数据类型也有对应的 Class 对象。
6. 方式六：`包装类.TYPE`
+ **前提**：针对基本数据类型的**包装类** (`Integer`, `Character`, etc.)。
+ **代码**：`Class cls = Integer.TYPE;`
+ **原理**：包装类内部有一个静态属性 `TYPE`，它指向对应的基本数据类型的 Class 对象。
+ **结论**：`int.class` 和 `Integer.TYPE` 是同一个对象。

public class GetClassDemo {

        Class<?> cls2 = Car.class;
        System.out.println(cls2);

        //方式三：对象.getClass()

        System.out.println(cls1.hashCode());
        System.out.println(cls2.hashCode());
        System.out.println(cls3.hashCode());
        System.out.println(cls4.hashCode());

        Class<Integer> integerClass = int.class;
        Class<Character> characterClass = char.class;
        Class<Boolean> booleanClass = boolean.class;
        System.out.println(integerClass);   //int

        //6. 方式六：基本数据类型对应的包装类
        Class<Integer> type1 = Integer.TYPE;
        Class<Character> type2 = Character.TYPE;
        System.out.println(type1);

        System.out.println(integerClass.hashCode() == type1.hashCode());    //true
    }

# 类加载
## 动态加载/静态加载
**反射 (Reflection)** 是 Java 实现动态语言的关键，通过反射可以实现类的动态加载。

| 类型 | 说明 | 特点 | 示例 |
| --- | --- | --- | --- |
| **静态加载** | 编译时加载相关的类。 | 依赖性强，如果类不存在，编译时就会报错。 | `new Dog()` |
| **动态加载** | 运行时加载需要的类。 | 依赖性弱，只有执行到该代码段时才加载，即使类不存在，只要不运行到该行也不报错。 | `Class.forName("com.test.Cat")` |


## 类加载时机
1. **创建对象时** (`new`) -> **静态加载**
2. **子类被加载时**，父类也会被加载 -> **静态加载**
3. **调用类的静态成员** (静态属性、静态方法) -> **静态加载**
4. **通过反射调用** -> **动态加载**
    - 例如：`Class.forName("com.test.Cat");`

### 加载(Loading)
+ **任务**：JVM 将字节码从不同的数据源（Class文件、Jar包、网络等）转化为**二进制字节流**加载到内存中。
+ **结果**：
    - 在**方法区**生成类的字节码二进制数据。
    - 在**堆区**生成一个代表该类的 `java.lang.Class` 对象，作为方法区数据的访问入口。

### 连接(Linking)
1. **验证 (Verification)**
+ **目的**：确保 Class 文件的字节流中包含的信息符合当前虚拟机的要求，且不会危害虚拟机自身的安全。
+ **内容**：
    - 文件格式验证（如：是否以魔数 `0xcafebabe` 开头）。
    - 元数据验证、字节码验证、符号引用验证。
+ **优化**：可以使用 `-Xverify:none` 参数关闭大部分验证措施，以缩短类加载时间。
2. **准备 (Preparation) -- 关键阶段**
+ **任务**：为类的**静态变量**分配内存，并将其初始化为**默认值**（如 0, 0L, null, false 等）。
+ **内存位置**：这些变量所使用的内存都将在**方法区**中进行分配。
+ **特殊情况**：`static final` (常量) 会在此阶段直接赋值为具体值，而不是默认值。

```java
class A {
    // 1. n1 是实例属性，不是静态变量。在准备阶段不会分配内存。
    public int n1 = 10;
    
    // 2. n2 是静态变量。在准备阶段分配内存，默认初始化为 0 (而不是20)。
    //    赋值为 20 的操作在“初始化”阶段才会执行。
    public static int n2 = 20;
    
    // 3. n3 是 static final (常量)。一旦赋值就不变。
    //    在准备阶段，n3 就会被赋值为 30。
    public static final int n3 = 30; 
}
```

3. **解析 (Resolution)**
+ **任务**：虚拟机将常量池内的**符号引用**替换为**直接引用**的过程。
+ **机制**：由 JVM 自动完成。

### 初始化（Initialization）
+ **说明**：到了此阶段，才真正开始执行类中定义的 Java 程序代码。
+ **本质**：执行 `<clinit>()` 方法的过程。
    - `<clinit>()` 方法由编译器自动收集类中的所有**静态变量的赋值动作**和**静态代码块**中的语句合并产生。
    - 收集顺序由语句在源文件中出现的顺序决定。
+ **线程安全**：
    - 虚拟机会保证一个类的 `<clinit>()` 方法在多线程环境中被正确地加锁、同步。
    - 如果多个线程同时初始化一个类，只有一个线程会执行 `<clinit>()`，其他线程阻塞等待。
    - **结论**：正是因为这个机制，保证了某个类在内存中只有一份 `Class` 对象。
+ **示例代码分析：**

```java
class B {
    // 静态代码块
    static {
        System.out.println("B 静态代码块被执行");
        num = 300;
    }

    // 静态变量定义
    static int num = 100;

    public B() {
        System.out.println("B() 构造器被执行");
    }
}
```

**加载 B 类时的执行逻辑 (**`**<clinit>()**`** 合并后):**

1. 执行 `System.out.println("B 静态代码块被执行");`
2. 执行 `num = 300;`
3. 执行 `num = 100;` (按顺序合并)
4. **最终结果**：`num` 的值为 100。

# 通过反射创建对象
## 创建方式
1. 方式一：直接调用 Class 类的 newInstance()
+ **前提**：类中必须有一个 **public** 修饰的**无参构造器**。
+ **局限性**：只能调用无参构造，且必须是 public 修饰的。
2. 方式二：使用 Constructor（构造器）对象
+ **步骤**：
    - 通过 `Class` 对象获取对应的 `Constructor` 对象。
    - 调用 `Constructor` 对象的 `newInstance(Object... obj)` 方法。
+ **优势**：可以调用无参或有参构造器，甚至可以调用私有 (private) 构造器。

## 关键 API 说明
1. java.lang.Class 类相关方法

| 方法名 | 说明 |
| --- | --- |
| `newInstance()` | 调用类的 public 无参构造器，返回对象实例。 |
| `getConstructor(Class... clazz)` | 根据参数列表，获取对应的 **public** 构造器对象。 |
| `getDeclaredConstructor(Class... clazz)` | 根据参数列表，获取对应的**所有**构造器对象 (包含 private, protected)。 |


2. java.lang.reflect.Constructor 类相关方法

| 方法名 | 说明 |
| --- | --- |
| `setAccessible(boolean flag)` | **暴破** (Violent Access)。<br/>设置为 `true` 时，表示反射对象在使用时取消访问检查。**这是访问 private 构造器的关键**。 |
| `newInstance(Object... initargs)` | 调用该构造器创建实例，需传入对应的实参。 |


## 代码示例
**案例要求：**

1. **测试 1**：通过反射创建 `User` 类的对象，使用 public 无参构造。
2. **测试 2**：通过反射创建 `User` 类的对象，使用 public 有参构造。
3. **测试 3**：通过反射创建 `User` 类的对象，使用 **private** 有参构造 (演示暴破)。

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

public class User {
    private String name = "jack";
    private int age = 10;

    //无参构造器
    public User() {
    }

    //pubLic修饰的有参构造器
    public User(String name) {
        this.name = name;
    }

    //private修饰的有参构造器
    private User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public String toString() {
        return "User{" +
                "name='" + name + '\'' +
                ", age=" + age +
                '}';
    }
}
```

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

import java.lang.reflect.Constructor;
import java.lang.reflect.InvocationTargetException;

public class ReflectCreateInstance {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException {

        Class<?> UserCls = Class.forName("com.aurora.ReflectionDemo.ReflectionFunction.User");

        //1.通过反射创建 User 类的对象，使用 public 无参构造。
        User user1 = (User) UserCls.newInstance();
        System.out.println(user1);

        //2.通过反射创建 User 类的对象，使用 public 有参构造。
        Constructor<?> constructor = UserCls.getConstructor(String.class);
        User user2 = (User) constructor.newInstance("tom");
        System.out.println(user2);

        //3.通过反射创建 User 类的对象，使用 private 有参构造 (演示暴破)。
        Constructor<?> constructor1 = UserCls.getDeclaredConstructor(String.class, int.class);  //此处不能使用getDeclared方法，因为getDeclared只能获取public修饰的构造器
        constructor1.setAccessible(true);
        User user3 = (User) constructor1.newInstance("jerry", 99);
        System.out.println(user3);
    }
}
```

# 通过反射访问类中的成员
## 访问属性
1. **获取属性对象**：使用 `getDeclaredField(String name)` 获取本类中定义的属性（包括 private）。
2. **暴破 (Violent Access)**：如果是私有属性，必须先调用 `setAccessible(true)` 关闭访问检查。
3. **操作属性**：
    - **设置值**: `f.set(o, 值)`
    - **获取值**: `f.get(o)`
4. 注意
+ 如果是静态属性 (`static`)，在 `set` 和 `get` 方法中，传入的对象参数 `o` 可以写成 `**null**`。因为静态属性是属于类的，不依赖于具体实例。

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

public class Student {
    public int age;
    private static String name;

    public Student() {
    }

    @Override
    public String toString() {
        return "Student{" +
                "age=" + age +
                ", name='" + name + '\'' +
                '}';
    }
}
```

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

import java.lang.reflect.Field;

public class ReflectVisitField {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchFieldException {

        //1. 得到Student类对应的 Class对象
        Class<?> StudentCls = Class.forName("com.aurora.ReflectionDemo.ReflectionFunction.Student");

        //2. 创建对象
        Student student = (Student) StudentCls.newInstance();

        //3. 使用反射得到public age 属性对象
        Field age = StudentCls.getField("age");
        age.set(student, 20);   //通过反射来操作属性
        System.out.println(student);    //Student{age=20, name='null'}
        System.out.println(age.get(student));   //20

        //4. 使用反射操作private static name 属性
        Field name = StudentCls.getDeclaredField("name");
        //对name 进行暴破, 可以操作private 属性
        name.setAccessible(true);
        name.set(null, "tom");  // 因为name是static属性，在类加载的时候就已经有了，因此 student 也可以写出null
        System.out.println(student);    //Student{age=20, name='tom'}
        System.out.println(name.get(student));  //tom
        System.out.println(name.get(null)); //获取属性值, 必须要求name是static tom
    }
}
```

## 访问方法
1. **获取方法对象**：使用 `getDeclaredMethod(String name, Class... parameterTypes)` 获取本类中定义的方法。
+ 需要传入方法名和形参类型的 Class 对象，以区分重载方法。
2. **暴破 (Violent Access)**：如果是私有方法，调用 `setAccessible(true)`。
3. **调用方法**：
+ `Object returnValue = m.invoke(o, 实参列表)`
4. 注意
+ **静态方法**：`invoke` 的第一个参数 `o` 可以写成 `**null**`。
+ **返回值**：`invoke` 方法统一返回 `Object` 类型，但其实际运行类型与方法定义的返回类型一致。

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

public class Monster {
}
```

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

public class Boss {
    public int age;
    private static String name;

    public Monster method1() {
        return new Monster();
    }

    //静态方法
    public static String say(int n, String s, char c) {
        return n + " " + s + " " +c;
    }

    //普通public方法
    public void hi(String s) {
        System.out.println( "hi," + s);
    }
}
```

```java
package com.aurora.ReflectionDemo.ReflectionFunction;

import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;

public class ReflectVisitMethod {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException {

        //1. 得到Boss类对应的Class对象
        Class<?> bossCls = Class.forName("com.aurora.ReflectionDemo.ReflectionFunction.Boss");

        //2. 创建对象
        Object o = bossCls.newInstance();

        //3. 调用public的hi方法
        Method hi = bossCls.getMethod("hi", String.class);
        hi.invoke(o,"tom");

        //4.调用private方法
        //4.1 得到 say 方法对象
        Method say = bossCls.getDeclaredMethod("say", int.class, String.class, char.class);
        //4.2 因为say方法是private, 所以需要暴破，原理和前面讲的构造器和属性一样
        say.setAccessible(true);
        System.out.println(say.invoke(o, 20, "tom", '男'));
        //4.3 因为say方法是static的，还可以这样调用 ，可以传入null
        System.out.println(say.invoke(null, 30, "mary", '女'));

        //5.在反射中，如果方法有返回值，同意返回Object，但是它的运行类型与方法定义的返回值类型已一致
        Object reVal = say.invoke(null, 18, "jerry", '男');
        System.out.println("reVal的运行类型是: " + reVal.getClass()); //reVal的运行类型是: class java.lang.String

        Method method1 = bossCls.getMethod("method1");
        Object reVal2 = method1.invoke(o);
        System.out.println("reVal2的运行类型是: " + reVal2.getClass());   //reVal2的运行类型是: class com.aurora.ReflectionDemo.ReflectionFunction.Monster
    }
}
```

## 练习 2：利用反射完成以下功能
1. <font style="color:rgb(31, 35, 40);">利用Class类的forName方法得到File类的class对象</font>
2. <font style="color:rgb(31, 35, 40);">在控制台打印File类的所有构造器</font>
3. <font style="color:rgb(31, 35, 40);">通过newInstance的方法创建File对象，并创在同级目录下创建 test.txt文件 提示:创建文件的正常写法如下: File file = new File("test.txt");//内存 file.createNewFile0;//方法，才能真正的创建文件</font>

```java
package com.aurora.ReflectionDemo.Practice;

import java.io.File;
import java.io.IOException;
import java.lang.reflect.Constructor;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;

public class Practice02 {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, InvocationTargetException, IOException, NoSuchMethodException {
        //1.利用Class类的forName方法得到File类的class对象
        Class<?> fileCls = Class.forName("java.io.File");

        //2.在控制台打印File类的所有构造器
        Constructor<?>[] constructors = fileCls.getDeclaredConstructors();
        for (Constructor<?> constructor : constructors) {
            System.out.println(constructor);
        }

        //3.通过newInstance的方法创建File对象，并创在同级目录下创建 test.txt文件
        //前面打印所有构造器是发现constructors[1]满足File(String.class),也可以直接使用constructors[0]
        //File file = (File) constructors[1].newInstance("module3/src/com/aurora/ReflectionDemo/Practice/test.txt");
        Constructor<?> constructor = fileCls.getDeclaredConstructor(String.class);
        File file = (File) constructor.newInstance("module3/src/com/aurora/ReflectionDemo/Practice/test.txt");

        Method createNewFile = fileCls.getMethod("createNewFile");
        createNewFile.invoke(file);
        System.out.println("文件创建成功");
    }
}
```
